# 企业创新访谈 AI · 小D

本机运行的企业创新访谈系统。围绕企业提供的业务场景与需求，从项目与方法库中发现跨行业参考，核对资料依据，形成创新方向与可验证的实施建议。

## 本次更新

- **深蓝界面**：固定 9:16 画布、深蓝渐变背景、对话与资料的内部滚动区；按最新要求移除对话栏上方左下装饰弧形。
- **真实关联图谱**：区分题录、已读资料和已评估关联；基于正文证据计算解释性关联分值。线宽、延伸长度与分值联动，未知值不视为零分，也不生成分值光束。
- **连续动效**：保留阶段间平滑交接；初始状态使用原休眠样式，正常完成后显示无拖尾的光点休眠；支持减少动态效果偏好。
- **分析过程与结果分离**：分析时展示收到的过程内容，最终答复出现后默认收起，可手动展开查看；调用详情独立显示。
- **自适应输出**：依据企业已提供的信息，选择简短初诊、部分章节或三部分十一章的完整报告结构。信息不足时不补造企业事实。
- **项目库连接与原件读取**：使用代码限定的项目库入口，保留公开摘录；原件遇到登录或授权限制时明确标记，不能冒称已读全文。
- **受控语音**：识别结果先进入输入框，由操作人确认发送。最终答复语音经配套转写与原文一致性核对后才播放；可选自动播报。

## 启动

要求 Node.js 22 或以上。WebSocket 依赖已随 `vendor/ws` 附带，无需额外安装依赖。

Windows 可双击 `启动企业访谈.bat`。也可在项目根目录执行：

```sh
npm start
```

打开 `http://127.0.0.1:5188/`，在「连接设置」填写自己的项目库访问密钥与百炼 API Key，并核对地域、业务空间、分析模型和音色设置。

项目与方法库当前入口由 `project-library.mjs` 限定为 `https://haoshejiguan.com/inno/mcp/api`。仅迁移代码中明确列出的旧入口，不向任意地址或重定向发送访问密钥。

## 从旧版更新

更新应用源码后保留自己已有的 `.local/` 目录，不覆盖 `config.json`。重新启动服务后，浏览器强制刷新，以加载新的 HTML、CSS 和脚本。

这份仓库只包含源码、应用资源、依赖和自动化测试。**不包含任何可直接使用的访问密钥、用户账号配置、访谈记录、公司资料、私人报告或本机备份。** 首次部署必须使用自己的授权配置。

本机服务默认仅监听 `127.0.0.1`，检查 Host 和修改请求的 Origin。请勿直接暴露到公网；公网部署需要另行设计认证、访问控制与 HTTPS。

## 验证

```sh
npm test
```

测试涵盖资料依据与关联评分、图谱几何、阶段动效、固定画布、深蓝主题、分析展示、自适应输出、语音一致性、本机访问限制和密钥保护。自动化测试使用模拟请求，不需要调用付费模型。

根目录保留的 `live-*.mjs`、`probe.mjs`、`*-benchmark.mjs` 和审计脚本是手动联调工具，部分会读取本机授权配置并访问外部服务；它们不属于 `npm test`，运行前应核对具体行为与费用。

## 主要目录

```text
public/                 页面、样式、图谱与交互脚本、应用资源
vendor/ws/              本地附带的 WebSocket 依赖及许可证
test/                   自动化测试
server.mjs              本机 HTTP 与语音服务
services.mjs            项目库与分析服务接入
project-library.mjs     项目库入口限制与兼容迁移
association-score.mjs   正文锚定的解释性关联评分
output-policy.mjs       企业信息评估与自适应报告结构
realtime-voice.mjs       语音输入与受控输出
```

## 使用边界

- 题录只证明候选项目存在，不等于已读正文、专家审核或工程验证。
- 分值是资料支撑下的解释性关联，不是成功率或投资收益预测。
- 建议区分来源事实、面向企业的迁移设想与待验证条件。
- 对话会话保存在服务端内存中，重启后需开始新访谈；当前没有持久化访谈报告保存或导出功能。
- 语音一致性检查依据服务商配套转写，不等于对音频进行第二次独立识别；现场麦克风、回声和真实服务商调用仍需另行测试。
