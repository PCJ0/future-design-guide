# 未来设计实验室 · 小 D 导览

以同学新版的首页、展厅布局、项目分类和按钮为界面基础。首页“开启语音导览”接入百炼实时语音，可语音介绍实验室、浏览全部 33 个项目及其图文与视频；访客也可使用屏幕按钮。选择“设计需求”或在语音中提出企业访谈、产业问题等关键词后，会进入企业需求访谈，由小 D 逐步了解问题，并检索 272 条本地知识记录后给出有资料依据的初步意见。

首页移除了背景中“玉环好设计馆”标题和下方标语；介绍文案改为未来设计实验室。项目页按提供的参考图组织为六类玻璃卡片，左侧保留动画小 D，并在小 D 上方实时显示语音回答文本；项目页不再显示独立麦克风入口。卡片显示的数量来自实际项目目录，不裁掉原项目来匹配参考图数字。

## 使用

- Mac：双击 `start-realtime.command`（或终端执行 `sh start-realtime.command`）。Windows：双击 `启动实时助手.bat`。打开 http://localhost:5173。
- 需要 Node.js 22 或更新版本；WebSocket 依赖已随 `scripts/vendor/ws` 本地附带，并保留许可，不需要 npm 安装。
- 实时语音：点击首页“开启语音导览”并配置自己的百炼账号后，可直接与小 D 语音交互；屏幕上的“实验室介绍”“设计需求”等入口仍可使用。语音说“设计需求”“企业访谈”或“产业问题”可进入企业访谈。账号配置保存在运行电脑的 `.local` 中，不包含在交付包里。
- 静态离线预览：打开 `review/yuhuan-guide-v9.html`；视频依赖相邻 `review/assets` 目录。离线预览不连接云端 API。
- 项目总览 → 选择类别 → 点击具体项目打开全屏图文；可通过实时语音调用项目、图片和视频。详情页“返回案例列表”回到当前类别；项目页“回到选择”逐级返回上一级，“回到首页”回到起始页。

## 编辑与验证

源码直接位于 `dist/`，不需要构建。`dist/lab-ui.js` 管理六类项目与项目列表；`dist/app.js` 保留前置动画和媒体联动；`dist/realtime.js`、`scripts/realtime-server.mjs` 沿用第二版的实时音频、打断、转写、知识检索和媒体工具。

运行 `node scripts/check.mjs` 检查语法、素材、知识库及模拟实时服务；运行 `node scripts/export-offline.mjs` 重新生成离线预览。API 验证使用本地模拟服务，未使用真实账号发起云端通话。

## 大屏展区版

- 背景全景铺满窗口；分类页所有项目自动排进一屏，没有滚动列表。33 个项目的详情统一为全屏图文展陈，完整保留原图、标题与说明。
- 项目页小 D 调整为略小的比例；移除独立麦克风按钮和语音示例按钮，语音回答显示在小 D 上方。项目页提供逐级“回到选择”和“回到首页”按钮；详情页提供“返回案例列表”。
- 访客语音可说“返回首页”“返回选择”“关闭详情”“下一个项目”“上一个项目”“下一个项目类别”“案例影像”。视频可说“暂停视频”“继续播放”“停止视频”，实时通话可说“结束对话”。实时模型通过原媒体工具协议执行这些操作。
- 配置账号后点击麦克风开启实时语音；连接时对话记录面板收起。管理员点击顶部“和小 D 实时对话”可展开通话控制。F 切换浏览器全屏，S 打开连接设置；Escape 退出当前详情。
- 视频全屏播放且不显示播放器控制条。离线文件不能连接实时模型，完整语音导航请通过本机服务运行。
- 页面在 1920×1080 下逐一检查全部 33 个详情：素材加载、全屏尺寸、文字完整且没有文字气泡；六个类别共 33 个项目均不需要滚动。

## 本轮对齐与入场修正

首页文字、启动按钮与小 D 共用屏幕中轴。移除项目总览副标题。删除旧的选择页播报覆盖，实际加载的四段前置文案和选择文案均按用户确认文本校验；选择实验室介绍后不额外播报。入口加入 4.6 秒的走入、减速、转身和页面渐入，与访谈入场保持相近节奏。
